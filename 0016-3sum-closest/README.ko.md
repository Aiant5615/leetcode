<h2><a href="https://leetcode.com/problems/3sum-closest">16. 3Sum Closest</a></h2><h3>Medium</h3><hr><p>정수 배열 <code>nums</code>와 정수 <code>target</code>이 주어질 때, 서로 다른 인덱스의 세 수를 골라 그 합이 <code>target</code>에 가장 가까운 합을 반환하세요. 답은 정확히 하나입니다.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> nums = [-1,2,1,-4], target = 1
<strong>출력:</strong> 2
<strong>설명:</strong> -1 + 2 + 1 = 2가 가장 가까운 합입니다.
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> nums = [0,0,0], target = 1
<strong>출력:</strong> 0
</pre>
<p><strong>제약 조건:</strong> <code>3 &lt;= nums.length &lt;= 500</code>, <code>-1000 &lt;= nums[i] &lt;= 1000</code>, <code>-10<sup>4</sup> &lt;= target &lt;= 10<sup>4</sup></code>.</p>
