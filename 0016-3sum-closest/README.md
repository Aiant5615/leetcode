<h2><a href="https://leetcode.com/problems/3sum-closest">16. 3Sum Closest</a></h2><h3>Medium</h3><hr><p>Given an integer array <code>nums</code> and an integer <code>target</code>, choose three numbers at different indices whose sum is closest to <code>target</code> and return that sum. Each input has exactly one answer.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> nums = [-1,2,1,-4], target = 1
<strong>Output:</strong> 2
<strong>Explanation:</strong> -1 + 2 + 1 = 2 is the closest sum.
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> nums = [0,0,0], target = 1
<strong>Output:</strong> 0
</pre>
<p><strong>Constraints:</strong> <code>3 &lt;= nums.length &lt;= 500</code>, <code>-1000 &lt;= nums[i] &lt;= 1000</code>, <code>-10<sup>4</sup> &lt;= target &lt;= 10<sup>4</sup></code>.</p>
