<h2><a href="https://leetcode.com/problems/decode-ways">91. Decode Ways</a></h2><h3>Medium</h3><hr><p>Letters are encoded as <code>'A' → "1"</code>, …, <code>'Z' → "26"</code>. Given a string of digits <code>s</code>, return the number of ways to decode it. Codes with a leading zero, such as <code>"06"</code>, are invalid.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> s = "12"
<strong>Output:</strong> 2
<strong>Explanation:</strong> "AB" (1 2) or "L" (12).
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> s = "226"
<strong>Output:</strong> 3
<strong>Explanation:</strong> "BZ", "VF", "BBF".
</pre>
<p><strong class="example">Example 3:</strong></p>
<pre>
<strong>Input:</strong> s = "06"
<strong>Output:</strong> 0
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= s.length &lt;= 100</code>.</p>
