<h2><a href="https://leetcode.com/problems/palindrome-number">9. Palindrome Number</a></h2><h3>Easy</h3><hr><p>정수 <code>x</code>가 주어질 때, 앞에서 읽어도 뒤에서 읽어도 같으면 <code>true</code>를 반환하세요. 음수는 회문이 아닙니다.</p>
<p><strong>예시 1:</strong></p>
<pre>
<strong>입력:</strong> x = 121
<strong>출력:</strong> true
</pre>
<p><strong>예시 2:</strong></p>
<pre>
<strong>입력:</strong> x = -121
<strong>출력:</strong> false
<strong>설명:</strong> 거꾸로 읽으면 "121-"입니다.
</pre>
<p><strong>예시 3:</strong></p>
<pre>
<strong>입력:</strong> x = 10
<strong>출력:</strong> false
</pre>
<p><strong>추가 질문:</strong> 정수를 문자열로 바꾸지 않고 풀 수 있나요?</p>
