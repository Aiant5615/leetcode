<h2><a href="https://leetcode.com/problems/generate-parentheses">22. Generate Parentheses</a></h2><h3>Medium</h3><hr><p>Given <code>n</code> pairs of parentheses, return every string of well-formed parentheses that uses all of them.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> n = 3
<strong>Output:</strong> ["((()))","(()())","(())()","()(())","()()()"]
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> n = 1
<strong>Output:</strong> ["()"]
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= n &lt;= 8</code>.</p>
