<h2><a href="https://leetcode.com/problems/divide-two-integers">29. Divide Two Integers</a></h2><h3>Medium</h3><hr><p>Divide <code>dividend</code> by <code>divisor</code> without using multiplication, division or mod, truncating toward zero. If the result is outside the 32-bit signed range, return <code>2<sup>31</sup> - 1</code> (or <code>-2<sup>31</sup></code>).</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> dividend = 10, divisor = 3
<strong>Output:</strong> 3
<strong>Explanation:</strong> 10/3 = 3.33… → 3.
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> dividend = 7, divisor = -3
<strong>Output:</strong> -2
</pre>
<p><strong>Constraints:</strong> <code>-2<sup>31</sup> &lt;= dividend, divisor &lt;= 2<sup>31</sup> - 1</code>, <code>divisor != 0</code>.</p>
