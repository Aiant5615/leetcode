<h2><a href="https://leetcode.com/problems/rotate-image">48. Rotate Image</a></h2><h3>Medium</h3><hr><p><code>n x n</code> 행렬을 시계 방향으로 90도 제자리에서 회전하세요(다른 행렬을 만들면 안 됩니다).</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> matrix = [[1,2,3],[4,5,6],[7,8,9]]
<strong>출력:</strong> [[7,4,1],[8,5,2],[9,6,3]]
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
<strong>출력:</strong> [[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= n &lt;= 20</code>.</p>
