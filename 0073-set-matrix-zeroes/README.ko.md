<h2><a href="https://leetcode.com/problems/set-matrix-zeroes">73. Set Matrix Zeroes</a></h2><h3>Medium</h3><hr><p><code>m x n</code> 행렬의 원소가 <code>0</code>이면 그 행과 열 전체를 <code>0</code>으로 제자리에서 바꾸세요. 추가 공간은 상수만 쓰도록 해 보세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> matrix = [[1,1,1],[1,0,1],[1,1,1]]
<strong>출력:</strong> [[1,0,1],[0,0,0],[1,0,1]]
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
<strong>출력:</strong> [[0,0,0,0],[0,4,5,0],[0,3,1,0]]
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= m, n &lt;= 200</code>.</p>
