<h2><a href="https://leetcode.com/problems/merge-intervals">56. Merge Intervals</a></h2><h3>Medium</h3><hr><p>Given an array of <code>intervals</code> <code>[start, end]</code>, merge all overlapping intervals and return the non-overlapping intervals that cover the same ranges.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> intervals = [[1,3],[2,6],[8,10],[15,18]]
<strong>Output:</strong> [[1,6],[8,10],[15,18]]
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> intervals = [[1,4],[4,5]]
<strong>Output:</strong> [[1,5]]
<strong>Explanation:</strong> Touching intervals overlap.
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= intervals.length &lt;= 10<sup>4</sup></code>.</p>
