# LeetCode

One problem a day, solved in C, C++, and Python. Solutions are pushed here automatically by the
[LeetHub](https://github.com/raphaelheinz/LeetHub-3.0) browser extension and shown on
https://aiant5615.github.io/leetcode/ (synced hourly).

## Layout

```
0001-two-sum/
  0001-two-sum.c
  0001-two-sum.cpp
  0001-two-sum.py
  README.md        # problem statement (written by LeetHub)
```

One folder per problem. The site reads the folder name, the README's title/difficulty, and the
first commit date of each solution file. Solutions added by hand work too — just follow the layout.

## LeetHub setup

1. Install LeetHub 3.0 (Chrome Web Store), sign in with GitHub, and pick this repo (`Aiant5615/leetcode`).
2. Solve a problem on leetcode.com. When a submission is **Accepted**, LeetHub commits it here.
3. Solve the same problem in the other two languages; each accepted submission adds a file to the same folder.

## Instant site sync (optional)

The site pulls this repo every hour. To update within a minute of each push, add a fine-grained
personal access token with `Actions: write` on the site repo as the secret `SITE_TOKEN` here;
`.github/workflows/notify-site.yml` then triggers the site's sync workflow on every push.
