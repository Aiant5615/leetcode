<h2><a href="https://leetcode.com/problems/add-binary">67. Add Binary</a></h2><h3>Easy</h3><hr><p>두 이진 문자열 <code>a</code>, <code>b</code>의 합을 이진 문자열로 반환하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> a = "11", b = "1"
<strong>출력:</strong> "100"
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> a = "1010", b = "1011"
<strong>출력:</strong> "10101"
</pre>
<p><strong>제약 조건:</strong> 길이 1~10<sup>4</sup>, <code>"0"</code>을 제외하면 앞자리 0이 없습니다.</p>
