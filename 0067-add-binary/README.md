<h2><a href="https://leetcode.com/problems/add-binary">67. Add Binary</a></h2><h3>Easy</h3><hr><p>Given two binary strings <code>a</code> and <code>b</code>, return their sum as a binary string.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> a = "11", b = "1"
<strong>Output:</strong> "100"
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> a = "1010", b = "1011"
<strong>Output:</strong> "10101"
</pre>
<p><strong>Constraints:</strong> lengths 1 to 10<sup>4</sup>, no leading zeros except <code>"0"</code>.</p>
