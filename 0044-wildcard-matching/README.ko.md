<h2><a href="https://leetcode.com/problems/wildcard-matching">44. Wildcard Matching</a></h2><h3>Hard</h3><hr><p>패턴 <code>p</code>가 문자열 <code>s</code> 전체와 일치하는지 판단하세요. <code>'?'</code>는 임의의 한 문자, <code>'*'</code>는 빈 문자열을 포함한 임의의 문자열과 일치합니다.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> s = "aa", p = "a"
<strong>출력:</strong> false
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> s = "aa", p = "*"
<strong>출력:</strong> true
</pre>
<p><strong class="example">예시 3:</strong></p>
<pre>
<strong>입력:</strong> s = "cb", p = "?a"
<strong>출력:</strong> false
</pre>
<p><strong>제약 조건:</strong> <code>0 &lt;= s.length, p.length &lt;= 2000</code>.</p>
