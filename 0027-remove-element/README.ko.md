<h2><a href="https://leetcode.com/problems/remove-element">27. Remove Element</a></h2><h3>Easy</h3><hr><p><code>nums</code>에서 <code>val</code>과 같은 값을 모두 제자리에서 제거하고 남은 원소의 개수 <code>k</code>를 반환하세요. 남은 원소는 앞 <code>k</code>칸에 있어야 하며 순서는 상관없습니다.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> nums = [3,2,2,3], val = 3
<strong>출력:</strong> 2, nums = [2,2,_,_]
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> nums = [0,1,2,2,3,0,4,2], val = 2
<strong>출력:</strong> 5, nums = [0,1,4,0,3,_,_,_]
</pre>
<p><strong>제약 조건:</strong> <code>0 &lt;= nums.length &lt;= 100</code>.</p>
