<h2><a href="https://leetcode.com/problems/remove-element">27. Remove Element</a></h2><h3>Easy</h3><hr><p>Remove every occurrence of <code>val</code> from <code>nums</code> in place and return the number <code>k</code> of remaining elements, which must occupy the first <code>k</code> slots (in any order).</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> nums = [3,2,2,3], val = 3
<strong>Output:</strong> 2, nums = [2,2,_,_]
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> nums = [0,1,2,2,3,0,4,2], val = 2
<strong>Output:</strong> 5, nums = [0,1,4,0,3,_,_,_]
</pre>
<p><strong>Constraints:</strong> <code>0 &lt;= nums.length &lt;= 100</code>.</p>
