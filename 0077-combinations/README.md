<h2><a href="https://leetcode.com/problems/combinations">77. Combinations</a></h2><h3>Medium</h3><hr><p>Return all combinations of <code>k</code> numbers chosen from <code>1</code> to <code>n</code>, in any order.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> n = 4, k = 2
<strong>Output:</strong> [[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> n = 1, k = 1
<strong>Output:</strong> [[1]]
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= k &lt;= n &lt;= 20</code>.</p>
