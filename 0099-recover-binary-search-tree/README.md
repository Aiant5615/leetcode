<h2><a href="https://leetcode.com/problems/recover-binary-search-tree">99. Recover Binary Search Tree</a></h2><h3>Medium</h3><hr><p>Exactly two nodes of a binary search tree had their values swapped by mistake. Recover the tree in place without changing its structure.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> root = [1,3,null,null,2]
<strong>Output:</strong> [3,1,null,null,2]
<strong>Explanation:</strong> Swapping 1 and 3 makes it valid.
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> root = [3,1,4,null,null,2]
<strong>Output:</strong> [2,1,4,null,null,3]
</pre>
<p><strong>Constraints:</strong> 2 to 1000 nodes.</p>
