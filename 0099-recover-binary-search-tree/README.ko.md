<h2><a href="https://leetcode.com/problems/recover-binary-search-tree">99. Recover Binary Search Tree</a></h2><h3>Medium</h3><hr><p>이진 탐색 트리에서 정확히 두 노드의 값이 실수로 바뀌었습니다. 구조를 바꾸지 않고 제자리에서 트리를 복구하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> root = [1,3,null,null,2]
<strong>출력:</strong> [3,1,null,null,2]
<strong>설명:</strong> 1과 3을 바꾸면 올바른 BST가 됩니다.
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> root = [3,1,4,null,null,2]
<strong>출력:</strong> [2,1,4,null,null,3]
</pre>
<p><strong>제약 조건:</strong> 노드 수는 2~1000입니다.</p>
