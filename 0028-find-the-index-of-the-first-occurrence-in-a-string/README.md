<h2><a href="https://leetcode.com/problems/find-the-index-of-the-first-occurrence-in-a-string">28. Find the Index of the First Occurrence in a String</a></h2><h3>Easy</h3><hr><p>Return the index of the first occurrence of <code>needle</code> in <code>haystack</code>, or <code>-1</code> if it does not occur.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> haystack = "sadbutsad", needle = "sad"
<strong>Output:</strong> 0
<strong>Explanation:</strong> "sad" occurs at 0 and 6; the first is 0.
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> haystack = "leetcode", needle = "leeto"
<strong>Output:</strong> -1
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= haystack.length, needle.length &lt;= 10<sup>4</sup></code>.</p>
