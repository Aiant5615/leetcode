<h2><a href="https://leetcode.com/problems/find-the-index-of-the-first-occurrence-in-a-string">28. Find the Index of the First Occurrence in a String</a></h2><h3>Easy</h3><hr><p><code>haystack</code>에서 <code>needle</code>이 처음 나타나는 인덱스를 반환하세요. 없으면 <code>-1</code>을 반환합니다.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> haystack = "sadbutsad", needle = "sad"
<strong>출력:</strong> 0
<strong>설명:</strong> "sad"는 0과 6에 나오며 처음 위치는 0입니다.
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> haystack = "leetcode", needle = "leeto"
<strong>출력:</strong> -1
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= haystack.length, needle.length &lt;= 10<sup>4</sup></code>.</p>
