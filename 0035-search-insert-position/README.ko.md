<h2><a href="https://leetcode.com/problems/search-insert-position">35. Search Insert Position</a></h2><h3>Easy</h3><hr><p>서로 다른 정수로 된 정렬 배열과 <code>target</code>이 주어질 때, 있으면 그 인덱스를, 없으면 순서를 유지하며 삽입될 위치를 반환하세요. <code>O(log n)</code>이어야 합니다.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> nums = [1,3,5,6], target = 5
<strong>출력:</strong> 2
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> nums = [1,3,5,6], target = 2
<strong>출력:</strong> 1
</pre>
<p><strong class="example">예시 3:</strong></p>
<pre>
<strong>입력:</strong> nums = [1,3,5,6], target = 7
<strong>출력:</strong> 4
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= nums.length &lt;= 10<sup>4</sup></code>.</p>
