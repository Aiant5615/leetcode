<h2><a href="https://leetcode.com/problems/search-in-rotated-sorted-array-ii">81. Search in Rotated Sorted Array II</a></h2><h3>Medium</h3><hr><p>A non-decreasing array (possibly with duplicates) was rotated at an unknown pivot. Return whether <code>target</code> is in it, doing as few steps as possible.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> nums = [2,5,6,0,0,1,2], target = 0
<strong>Output:</strong> true
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> nums = [2,5,6,0,0,1,2], target = 3
<strong>Output:</strong> false
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= nums.length &lt;= 5000</code>.</p>
