<h2><a href="https://leetcode.com/problems/sort-colors">75. Sort Colors</a></h2><h3>Medium</h3><hr><p><code>0</code>, <code>1</code>, <code>2</code>(빨강, 흰색, 파랑)로 이루어진 배열을 라이브러리 정렬 없이 한 번의 순회로 제자리 정렬하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> nums = [2,0,2,1,1,0]
<strong>출력:</strong> [0,0,1,1,2,2]
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> nums = [2,0,1]
<strong>출력:</strong> [0,1,2]
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= n &lt;= 300</code>.</p>
