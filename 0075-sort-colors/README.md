<h2><a href="https://leetcode.com/problems/sort-colors">75. Sort Colors</a></h2><h3>Medium</h3><hr><p>Sort an array of <code>0</code>s, <code>1</code>s and <code>2</code>s (red, white, blue) in place, in one pass and without a library sort.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> nums = [2,0,2,1,1,0]
<strong>Output:</strong> [0,0,1,1,2,2]
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> nums = [2,0,1]
<strong>Output:</strong> [0,1,2]
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= n &lt;= 300</code>.</p>
