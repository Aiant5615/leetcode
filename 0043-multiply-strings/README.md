<h2><a href="https://leetcode.com/problems/multiply-strings">43. Multiply Strings</a></h2><h3>Medium</h3><hr><p>Given two non-negative integers <code>num1</code> and <code>num2</code> as strings, return their product as a string, without converting the inputs to integers directly or using big-integer libraries.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> num1 = "2", num2 = "3"
<strong>Output:</strong> "6"
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> num1 = "123", num2 = "456"
<strong>Output:</strong> "56088"
</pre>
<p><strong>Constraints:</strong> lengths 1 to 200, digits only, no leading zeros except <code>"0"</code>.</p>
