<h2><a href="https://leetcode.com/problems/multiply-strings">43. Multiply Strings</a></h2><h3>Medium</h3><hr><p>문자열로 주어진 음이 아닌 두 정수 <code>num1</code>, <code>num2</code>의 곱을 문자열로 반환하세요. 입력을 정수로 직접 변환하거나 큰 정수 라이브러리를 쓰면 안 됩니다.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> num1 = "2", num2 = "3"
<strong>출력:</strong> "6"
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> num1 = "123", num2 = "456"
<strong>출력:</strong> "56088"
</pre>
<p><strong>제약 조건:</strong> 길이 1~200, 숫자만 있으며 <code>"0"</code>을 제외하면 앞자리 0이 없습니다.</p>
