<h2><a href="https://leetcode.com/problems/minimum-path-sum">64. Minimum Path Sum</a></h2><h3>Medium</h3><hr><p>음이 아닌 수로 채워진 <code>m x n</code> 격자에서 오른쪽이나 아래로만 움직여 왼쪽 위에서 오른쪽 아래까지 갈 때, 지나는 수의 합이 최소인 경로의 합을 반환하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> grid = [[1,3,1],[1,5,1],[4,2,1]]
<strong>출력:</strong> 7
<strong>설명:</strong> 1→3→1→1→1.
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> grid = [[1,2,3],[4,5,6]]
<strong>출력:</strong> 12
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= m, n &lt;= 200</code>.</p>
