<h2><a href="https://leetcode.com/problems/minimum-path-sum">64. Minimum Path Sum</a></h2><h3>Medium</h3><hr><p>Given an <code>m x n</code> grid of non-negative numbers, find a path from the top-left to the bottom-right corner, moving only right or down, that minimizes the sum of the numbers on it. Return that sum.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> grid = [[1,3,1],[1,5,1],[4,2,1]]
<strong>Output:</strong> 7
<strong>Explanation:</strong> 1→3→1→1→1.
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> grid = [[1,2,3],[4,5,6]]
<strong>Output:</strong> 12
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= m, n &lt;= 200</code>.</p>
