<h2><a href="https://leetcode.com/problems/3sum">15. 3Sum</a></h2><h3>Medium</h3><hr><p>Given an integer array <code>nums</code>, return all distinct triplets <code>[nums[i], nums[j], nums[k]]</code> with <code>i</code>, <code>j</code>, <code>k</code> all different and <code>nums[i] + nums[j] + nums[k] == 0</code>. The answer must not contain duplicate triplets.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> nums = [-1,0,1,2,-1,-4]
<strong>Output:</strong> [[-1,-1,2],[-1,0,1]]
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> nums = [0,1,1]
<strong>Output:</strong> []
</pre>
<p><strong class="example">Example 3:</strong></p>
<pre>
<strong>Input:</strong> nums = [0,0,0]
<strong>Output:</strong> [[0,0,0]]
</pre>
<p><strong>Constraints:</strong> <code>3 &lt;= nums.length &lt;= 3000</code>, <code>-10<sup>5</sup> &lt;= nums[i] &lt;= 10<sup>5</sup></code>.</p>
