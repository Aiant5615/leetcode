<h2><a href="https://leetcode.com/problems/3sum">15. 3Sum</a></h2><h3>Medium</h3><hr><p>정수 배열 <code>nums</code>에서 서로 다른 인덱스 <code>i</code>, <code>j</code>, <code>k</code>에 대해 <code>nums[i] + nums[j] + nums[k] == 0</code>인 세 수의 조합을 모두 반환하세요. 같은 조합이 중복되면 안 됩니다.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> nums = [-1,0,1,2,-1,-4]
<strong>출력:</strong> [[-1,-1,2],[-1,0,1]]
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> nums = [0,1,1]
<strong>출력:</strong> []
</pre>
<p><strong class="example">예시 3:</strong></p>
<pre>
<strong>입력:</strong> nums = [0,0,0]
<strong>출력:</strong> [[0,0,0]]
</pre>
<p><strong>제약 조건:</strong> <code>3 &lt;= nums.length &lt;= 3000</code>, <code>-10<sup>5</sup> &lt;= nums[i] &lt;= 10<sup>5</sup></code>.</p>
