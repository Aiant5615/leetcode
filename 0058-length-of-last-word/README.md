<h2><a href="https://leetcode.com/problems/length-of-last-word">58. Length of Last Word</a></h2><h3>Easy</h3><hr><p>Given a string <code>s</code> of words separated by spaces, return the length of the last word (a maximal run of non-space characters).</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> s = "Hello World"
<strong>Output:</strong> 5
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> s = "   fly me   to   the moon  "
<strong>Output:</strong> 4
</pre>
<p><strong class="example">Example 3:</strong></p>
<pre>
<strong>Input:</strong> s = "luffy is still joyboy"
<strong>Output:</strong> 6
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= s.length &lt;= 10<sup>4</sup></code>; there is at least one word.</p>
