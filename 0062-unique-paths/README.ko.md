<h2><a href="https://leetcode.com/problems/unique-paths">62. Unique Paths</a></h2><h3>Medium</h3><hr><p>로봇이 <code>m x n</code> 격자의 왼쪽 위에서 출발해 오른쪽이나 아래로만 움직입니다. 오른쪽 아래 모서리까지 가는 서로 다른 경로의 수를 반환하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> m = 3, n = 7
<strong>출력:</strong> 28
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> m = 3, n = 2
<strong>출력:</strong> 3
<strong>설명:</strong> 오른쪽→아래→아래, 아래→아래→오른쪽, 아래→오른쪽→아래.
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= m, n &lt;= 100</code>, 답은 32비트에 들어갑니다.</p>
