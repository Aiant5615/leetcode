<h2><a href="https://leetcode.com/problems/unique-paths">62. Unique Paths</a></h2><h3>Medium</h3><hr><p>A robot starts at the top-left corner of an <code>m x n</code> grid and can only move right or down. Return the number of distinct paths to the bottom-right corner.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> m = 3, n = 7
<strong>Output:</strong> 28
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> m = 3, n = 2
<strong>Output:</strong> 3
<strong>Explanation:</strong> Right→Down→Down, Down→Down→Right, Down→Right→Down.
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= m, n &lt;= 100</code>; the answer fits in 32 bits.</p>
