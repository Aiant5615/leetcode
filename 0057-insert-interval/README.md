<h2><a href="https://leetcode.com/problems/insert-interval">57. Insert Interval</a></h2><h3>Medium</h3><hr><p>You are given non-overlapping <code>intervals</code> sorted by start, and a <code>newInterval</code>. Insert it so the list stays sorted and non-overlapping (merge where needed) and return the result.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> intervals = [[1,3],[6,9]], newInterval = [2,5]
<strong>Output:</strong> [[1,5],[6,9]]
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]], newInterval = [4,8]
<strong>Output:</strong> [[1,2],[3,10],[12,16]]
</pre>
<p><strong>Constraints:</strong> <code>0 &lt;= intervals.length &lt;= 10<sup>4</sup></code>.</p>
