<h2><a href="https://leetcode.com/problems/n-queens">51. N-Queens</a></h2><h3>Hard</h3><hr><p>Place <code>n</code> queens on an <code>n x n</code> chessboard so that no two attack each other (same row, column or diagonal). Return every distinct board, each as a list of strings where <code>'Q'</code> is a queen and <code>'.'</code> an empty square.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> n = 4
<strong>Output:</strong> [[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> n = 1
<strong>Output:</strong> [["Q"]]
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= n &lt;= 9</code>.</p>
