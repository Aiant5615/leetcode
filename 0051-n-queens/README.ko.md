<h2><a href="https://leetcode.com/problems/n-queens">51. N-Queens</a></h2><h3>Hard</h3><hr><p><code>n x n</code> 체스판에 퀸 <code>n</code>개를 서로 공격하지 않게(같은 행·열·대각선 금지) 놓는 서로 다른 배치를 모두 반환하세요. 각 배치는 문자열 목록이며 <code>'Q'</code>는 퀸, <code>'.'</code>는 빈칸입니다.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> n = 4
<strong>출력:</strong> [[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> n = 1
<strong>출력:</strong> [["Q"]]
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= n &lt;= 9</code>.</p>
