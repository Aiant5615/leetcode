<h2><a href="https://leetcode.com/problems/remove-duplicates-from-sorted-list-ii">82. Remove Duplicates from Sorted List II</a></h2><h3>Medium</h3><hr><p>정렬된 연결 리스트의 head가 주어질 때, 두 번 이상 나오는 값의 노드를 모두 지우고 원래 리스트에서 한 번만 나온 값만 남기세요. 정렬된 결과를 반환합니다.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> head = [1,2,3,3,4,4,5]
<strong>출력:</strong> [1,2,5]
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> head = [1,1,1,2,3]
<strong>출력:</strong> [2,3]
</pre>
<p><strong>제약 조건:</strong> 노드 수는 0~300입니다.</p>
