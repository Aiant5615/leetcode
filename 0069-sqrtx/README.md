<h2><a href="https://leetcode.com/problems/sqrtx">69. Sqrt(x)</a></h2><h3>Easy</h3><hr><p>Given a non-negative integer <code>x</code>, return the square root of <code>x</code> rounded down, without using built-in power or square-root functions.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> x = 4
<strong>Output:</strong> 2
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> x = 8
<strong>Output:</strong> 2
<strong>Explanation:</strong> √8 = 2.828…, rounded down to 2.
</pre>
<p><strong>Constraints:</strong> <code>0 &lt;= x &lt;= 2<sup>31</sup> - 1</code>.</p>
