<h2><a href="https://leetcode.com/problems/sqrtx">69. Sqrt(x)</a></h2><h3>Easy</h3><hr><p>음이 아닌 정수 <code>x</code>의 제곱근을 내림한 값을, 내장 거듭제곱·제곱근 함수 없이 반환하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> x = 4
<strong>출력:</strong> 2
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> x = 8
<strong>출력:</strong> 2
<strong>설명:</strong> √8 = 2.828…, 내림하면 2입니다.
</pre>
<p><strong>제약 조건:</strong> <code>0 &lt;= x &lt;= 2<sup>31</sup> - 1</code>.</p>
