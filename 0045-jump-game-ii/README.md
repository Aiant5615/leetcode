<h2><a href="https://leetcode.com/problems/jump-game-ii">45. Jump Game II</a></h2><h3>Medium</h3><hr><p>You start at index 0 of <code>nums</code>; <code>nums[i]</code> is the maximum jump length from index <code>i</code>. Return the minimum number of jumps to reach the last index (it is always reachable).</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> nums = [2,3,1,1,4]
<strong>Output:</strong> 2
<strong>Explanation:</strong> 0 → 1 → 4.
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> nums = [2,3,0,1,4]
<strong>Output:</strong> 2
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= nums.length &lt;= 10<sup>4</sup></code>, <code>0 &lt;= nums[i] &lt;= 1000</code>.</p>
