<h2><a href="https://leetcode.com/problems/jump-game-ii">45. Jump Game II</a></h2><h3>Medium</h3><hr><p><code>nums</code>의 인덱스 0에서 시작하며, <code>nums[i]</code>는 인덱스 <code>i</code>에서 뛸 수 있는 최대 거리입니다. 마지막 인덱스에 도달하는 최소 점프 횟수를 반환하세요(항상 도달 가능합니다).</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> nums = [2,3,1,1,4]
<strong>출력:</strong> 2
<strong>설명:</strong> 0 → 1 → 4.
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> nums = [2,3,0,1,4]
<strong>출력:</strong> 2
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= nums.length &lt;= 10<sup>4</sup></code>, <code>0 &lt;= nums[i] &lt;= 1000</code>.</p>
