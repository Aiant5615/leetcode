<h2><a href="https://leetcode.com/problems/gray-code">89. Gray Code</a></h2><h3>Medium</h3><hr><p><code>n</code>비트 그레이 코드 수열을 하나 반환하세요. <code>[0, 2<sup>n</sup> - 1]</code> 범위의 서로 다른 정수 <code>2<sup>n</sup></code>개로 0에서 시작하며, 이웃한 값(마지막과 처음 포함)은 정확히 한 비트만 다릅니다.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> n = 2
<strong>출력:</strong> [0,1,3,2]
<strong>설명:</strong> 00, 01, 11, 10.
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> n = 1
<strong>출력:</strong> [0,1]
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= n &lt;= 16</code>.</p>
