<h2><a href="https://leetcode.com/problems/gray-code">89. Gray Code</a></h2><h3>Medium</h3><hr><p>Return any <code>n</code>-bit Gray code sequence: <code>2<sup>n</sup></code> distinct integers in <code>[0, 2<sup>n</sup> - 1]</code>, starting at 0, where consecutive values (and the last and first) differ in exactly one bit.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> n = 2
<strong>Output:</strong> [0,1,3,2]
<strong>Explanation:</strong> 00, 01, 11, 10.
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> n = 1
<strong>Output:</strong> [0,1]
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= n &lt;= 16</code>.</p>
