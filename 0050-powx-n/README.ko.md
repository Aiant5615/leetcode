<h2><a href="https://leetcode.com/problems/powx-n">50. Pow(x, n)</a></h2><h3>Medium</h3><hr><p><code>x</code>를 정수 <code>n</code>제곱(<code>n</code>은 음수일 수 있음)하는 <code>pow(x, n)</code>을 구현하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> x = 2.00000, n = 10
<strong>출력:</strong> 1024.00000
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> x = 2.10000, n = 3
<strong>출력:</strong> 9.26100
</pre>
<p><strong class="example">예시 3:</strong></p>
<pre>
<strong>입력:</strong> x = 2.00000, n = -2
<strong>출력:</strong> 0.25000
<strong>설명:</strong> 2<sup>-2</sup> = 1/4.
</pre>
<p><strong>제약 조건:</strong> <code>-100.0 &lt; x &lt; 100.0</code>, <code>-2<sup>31</sup> &lt;= n &lt;= 2<sup>31</sup> - 1</code>.</p>
