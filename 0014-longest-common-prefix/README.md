<h2><a href="https://leetcode.com/problems/longest-common-prefix">14. Longest Common Prefix</a></h2><h3>Easy</h3><hr><p>Return the longest string that is a prefix of every string in the array <code>strs</code>, or <code>""</code> if there is none.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> strs = ["flower","flow","flight"]
<strong>Output:</strong> "fl"
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> strs = ["dog","racecar","car"]
<strong>Output:</strong> ""
<strong>Explanation:</strong> No common prefix.
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= strs.length &lt;= 200</code>, <code>0 &lt;= strs[i].length &lt;= 200</code>, lowercase letters only.</p>
