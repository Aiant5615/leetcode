<h2><a href="https://leetcode.com/problems/longest-common-prefix">14. Longest Common Prefix</a></h2><h3>Easy</h3><hr><p>배열 <code>strs</code>의 모든 문자열에 공통으로 붙어 있는 가장 긴 접두사를 반환하세요. 없으면 <code>""</code>를 반환합니다.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> strs = ["flower","flow","flight"]
<strong>출력:</strong> "fl"
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> strs = ["dog","racecar","car"]
<strong>출력:</strong> ""
<strong>설명:</strong> 공통 접두사가 없습니다.
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= strs.length &lt;= 200</code>, <code>0 &lt;= strs[i].length &lt;= 200</code>, 영어 소문자만 사용합니다.</p>
