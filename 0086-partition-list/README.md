<h2><a href="https://leetcode.com/problems/partition-list">86. Partition List</a></h2><h3>Medium</h3><hr><p>Given the head of a linked list and a value <code>x</code>, reorder it so that all nodes less than <code>x</code> come before nodes greater than or equal to <code>x</code>, keeping the original relative order within each part.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> head = [1,4,3,2,5,2], x = 3
<strong>Output:</strong> [1,2,2,4,3,5]
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> head = [2,1], x = 2
<strong>Output:</strong> [1,2]
</pre>
<p><strong>Constraints:</strong> 0 to 200 nodes.</p>
