<h2><a href="https://leetcode.com/problems/partition-list">86. Partition List</a></h2><h3>Medium</h3><hr><p>연결 리스트의 head와 값 <code>x</code>가 주어질 때, <code>x</code>보다 작은 노드가 <code>x</code> 이상인 노드보다 모두 앞에 오도록 재배열하세요. 각 부분 안의 원래 순서는 유지합니다.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> head = [1,4,3,2,5,2], x = 3
<strong>출력:</strong> [1,2,2,4,3,5]
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> head = [2,1], x = 2
<strong>출력:</strong> [1,2]
</pre>
<p><strong>제약 조건:</strong> 노드 수는 0~200입니다.</p>
