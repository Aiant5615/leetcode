<h2><a href="https://leetcode.com/problems/zigzag-conversion">6. Zigzag Conversion</a></h2><h3>Medium</h3><hr><p>Write the string <code>s</code> in a zigzag pattern on <code>numRows</code> rows (down the first column, then diagonally up to the top, then down again, and so on), and return the characters read row by row.</p>
<pre>
P   A   H   N
A P L S I I G
Y   I   R
</pre>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> s = "PAYPALISHIRING", numRows = 3
<strong>Output:</strong> "PAHNAPLSIIGYIR"
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> s = "PAYPALISHIRING", numRows = 4
<strong>Output:</strong> "PINALSIGYAHRPI"
</pre>
<p><strong class="example">Example 3:</strong></p>
<pre>
<strong>Input:</strong> s = "A", numRows = 1
<strong>Output:</strong> "A"
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= s.length &lt;= 1000</code>, <code>1 &lt;= numRows &lt;= 1000</code>.</p>
