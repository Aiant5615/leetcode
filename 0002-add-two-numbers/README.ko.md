<h2><a href="https://leetcode.com/problems/add-two-numbers">2. Add Two Numbers</a></h2><h3>Medium</h3><hr><p>음이 아닌 두 정수가 비어 있지 않은 연결 리스트로 주어집니다. 각 자릿수는 <strong>거꾸로</strong>, 노드 하나에 한 자리씩 저장되어 있습니다. 두 수를 더한 값을 같은 형식의 연결 리스트로 반환하세요.</p>
<p>0 자체를 제외하면 두 수 모두 앞자리에 0이 없습니다.</p>
<p><strong>예시 1:</strong></p>
<pre>
<strong>입력:</strong> l1 = [2,4,3], l2 = [5,6,4]
<strong>출력:</strong> [7,0,8]
<strong>설명:</strong> 342 + 465 = 807.
</pre>
<p><strong>예시 2:</strong></p>
<pre>
<strong>입력:</strong> l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
<strong>출력:</strong> [8,9,9,9,0,0,0,1]
</pre>
<p><strong>제약 조건:</strong></p>
<ul><li>각 리스트의 노드 수는 1개 이상 100개 이하입니다.</li><li><code>0 &lt;= Node.val &lt;= 9</code></li></ul>
