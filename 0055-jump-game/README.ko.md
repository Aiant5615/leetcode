<h2><a href="https://leetcode.com/problems/jump-game">55. Jump Game</a></h2><h3>Medium</h3><hr><p><code>nums</code>의 인덱스 0에서 시작하며 <code>nums[i]</code>는 인덱스 <code>i</code>에서 뛸 수 있는 최대 거리입니다. 마지막 인덱스에 도달할 수 있는지 반환하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> nums = [2,3,1,1,4]
<strong>출력:</strong> true
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> nums = [3,2,1,0,4]
<strong>출력:</strong> false
<strong>설명:</strong> 항상 점프 거리가 0인 인덱스 3에 멈춥니다.
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= nums.length &lt;= 10<sup>4</sup></code>.</p>
