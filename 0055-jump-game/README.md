<h2><a href="https://leetcode.com/problems/jump-game">55. Jump Game</a></h2><h3>Medium</h3><hr><p>You start at index 0 of <code>nums</code>; <code>nums[i]</code> is the maximum jump length from index <code>i</code>. Return whether you can reach the last index.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> nums = [2,3,1,1,4]
<strong>Output:</strong> true
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> nums = [3,2,1,0,4]
<strong>Output:</strong> false
<strong>Explanation:</strong> You always land on index 3, whose jump length is 0.
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= nums.length &lt;= 10<sup>4</sup></code>.</p>
