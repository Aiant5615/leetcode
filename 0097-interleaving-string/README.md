<h2><a href="https://leetcode.com/problems/interleaving-string">97. Interleaving String</a></h2><h3>Medium</h3><hr><p>Return whether <code>s3</code> can be formed by interleaving <code>s1</code> and <code>s2</code>: splitting each into substrings and alternating them while keeping each string's characters in order.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> s1 = "aabcc", s2 = "dbbca", s3 = "aadbbcbcac"
<strong>Output:</strong> true
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> s1 = "aabcc", s2 = "dbbca", s3 = "aadbbbaccc"
<strong>Output:</strong> false
</pre>
<p><strong class="example">Example 3:</strong></p>
<pre>
<strong>Input:</strong> s1 = "", s2 = "", s3 = ""
<strong>Output:</strong> true
</pre>
<p><strong>Constraints:</strong> <code>0 &lt;= s1.length, s2.length &lt;= 100</code>.</p>
