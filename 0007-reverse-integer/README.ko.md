<h2><a href="https://leetcode.com/problems/reverse-integer">7. Reverse Integer</a></h2><h3>Medium</h3><hr><p>32비트 부호 있는 정수 <code>x</code>가 주어질 때, 자릿수를 뒤집은 값을 반환하세요. 결과가 32비트 범위 <code>[-2<sup>31</sup>, 2<sup>31</sup> - 1]</code>를 벗어나면 <code>0</code>을 반환합니다. 64비트 정수는 사용할 수 없다고 가정합니다.</p>
<p><strong>예시 1:</strong></p>
<pre>
<strong>입력:</strong> x = 123
<strong>출력:</strong> 321
</pre>
<p><strong>예시 2:</strong></p>
<pre>
<strong>입력:</strong> x = -123
<strong>출력:</strong> -321
</pre>
<p><strong>예시 3:</strong></p>
<pre>
<strong>입력:</strong> x = 120
<strong>출력:</strong> 21
</pre>
