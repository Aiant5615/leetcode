<h2><a href="https://leetcode.com/problems/reverse-linked-list-ii">92. Reverse Linked List II</a></h2><h3>Medium</h3><hr><p>연결 리스트에서 <code>left</code>번째부터 <code>right</code>번째(1부터, 양 끝 포함) 노드를 뒤집고 head를 반환하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> head = [1,2,3,4,5], left = 2, right = 4
<strong>출력:</strong> [1,4,3,2,5]
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> head = [5], left = 1, right = 1
<strong>출력:</strong> [5]
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= left &lt;= right &lt;= n &lt;= 500</code>.</p>
