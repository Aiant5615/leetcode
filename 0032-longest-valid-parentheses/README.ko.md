<h2><a href="https://leetcode.com/problems/longest-valid-parentheses">32. Longest Valid Parentheses</a></h2><h3>Hard</h3><hr><p><code>'('</code>와 <code>')'</code>로만 이루어진 문자열에서 올바른 괄호를 이루는 가장 긴 부분 문자열의 길이를 반환하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> s = "(()"
<strong>출력:</strong> 2
<strong>설명:</strong> 가장 긴 것은 "()"입니다.
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> s = ")()())"
<strong>출력:</strong> 4
<strong>설명:</strong> 가장 긴 것은 "()()"입니다.
</pre>
<p><strong class="example">예시 3:</strong></p>
<pre>
<strong>입력:</strong> s = ""
<strong>출력:</strong> 0
</pre>
<p><strong>제약 조건:</strong> <code>0 &lt;= s.length &lt;= 3 * 10<sup>4</sup></code>.</p>
