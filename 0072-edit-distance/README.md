<h2><a href="https://leetcode.com/problems/edit-distance">72. Edit Distance</a></h2><h3>Medium</h3><hr><p>Return the minimum number of single-character insertions, deletions and replacements needed to turn <code>word1</code> into <code>word2</code>.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> word1 = "horse", word2 = "ros"
<strong>Output:</strong> 3
<strong>Explanation:</strong> horse → rorse → rose → ros.
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> word1 = "intention", word2 = "execution"
<strong>Output:</strong> 5
</pre>
<p><strong>Constraints:</strong> <code>0 &lt;= word1.length, word2.length &lt;= 500</code>.</p>
