<h2><a href="https://leetcode.com/problems/edit-distance">72. Edit Distance</a></h2><h3>Medium</h3><hr><p><code>word1</code>을 <code>word2</code>로 바꾸는 데 필요한 한 글자 삽입·삭제·교체 연산의 최소 횟수를 반환하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> word1 = "horse", word2 = "ros"
<strong>출력:</strong> 3
<strong>설명:</strong> horse → rorse → rose → ros.
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> word1 = "intention", word2 = "execution"
<strong>출력:</strong> 5
</pre>
<p><strong>제약 조건:</strong> <code>0 &lt;= word1.length, word2.length &lt;= 500</code>.</p>
