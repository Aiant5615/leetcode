<h2><a href="https://leetcode.com/problems/subsets">78. Subsets</a></h2><h3>Medium</h3><hr><p>서로 다른 정수 배열 <code>nums</code>의 모든 부분집합(멱집합)을 중복 없이, 순서와 상관없이 반환하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> nums = [1,2,3]
<strong>출력:</strong> [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> nums = [0]
<strong>출력:</strong> [[],[0]]
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= nums.length &lt;= 10</code>.</p>
