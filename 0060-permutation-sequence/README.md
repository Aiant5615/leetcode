<h2><a href="https://leetcode.com/problems/permutation-sequence">60. Permutation Sequence</a></h2><h3>Hard</h3><hr><p>The permutations of <code>[1, 2, ..., n]</code> listed in lexicographic order are numbered from 1. Return the <code>k</code>-th permutation as a string.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> n = 3, k = 3
<strong>Output:</strong> "213"
<strong>Explanation:</strong> 123, 132, 213, …
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> n = 4, k = 9
<strong>Output:</strong> "2314"
</pre>
<p><strong class="example">Example 3:</strong></p>
<pre>
<strong>Input:</strong> n = 3, k = 1
<strong>Output:</strong> "123"
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= n &lt;= 9</code>, <code>1 &lt;= k &lt;= n!</code>.</p>
