<h2><a href="https://leetcode.com/problems/permutation-sequence">60. Permutation Sequence</a></h2><h3>Hard</h3><hr><p><code>[1, 2, ..., n]</code>의 순열을 사전순으로 나열하고 1번부터 번호를 붙일 때, <code>k</code>번째 순열을 문자열로 반환하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> n = 3, k = 3
<strong>출력:</strong> "213"
<strong>설명:</strong> 123, 132, 213, …
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> n = 4, k = 9
<strong>출력:</strong> "2314"
</pre>
<p><strong class="example">예시 3:</strong></p>
<pre>
<strong>입력:</strong> n = 3, k = 1
<strong>출력:</strong> "123"
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= n &lt;= 9</code>, <code>1 &lt;= k &lt;= n!</code>.</p>
