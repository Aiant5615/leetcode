<h2><a href="https://leetcode.com/problems/count-and-say">38. Count and Say</a></h2><h3>Medium</h3><hr><p>The count-and-say sequence starts with <code>&quot;1&quot;</code>; each next term reads the previous one aloud as run-length groups (<code>&quot;21&quot;</code> is one 2, one 1 → <code>&quot;1211&quot;</code>). Return the <code>n</code>-th term.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> n = 4
<strong>Output:</strong> "1211"
<strong>Explanation:</strong> 1 → 11 → 21 → 1211.
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> n = 1
<strong>Output:</strong> "1"
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= n &lt;= 30</code>.</p>
