<h2><a href="https://leetcode.com/problems/count-and-say">38. Count and Say</a></h2><h3>Medium</h3><hr><p>count-and-say 수열은 <code>&quot;1&quot;</code>에서 시작하고, 다음 항은 이전 항을 같은 숫자 묶음 단위로 소리 내어 읽은 것입니다(<code>&quot;21&quot;</code>은 2가 하나, 1이 하나 → <code>&quot;1211&quot;</code>). <code>n</code>번째 항을 반환하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> n = 4
<strong>출력:</strong> "1211"
<strong>설명:</strong> 1 → 11 → 21 → 1211.
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> n = 1
<strong>출력:</strong> "1"
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= n &lt;= 30</code>.</p>
