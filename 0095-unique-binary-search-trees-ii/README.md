<h2><a href="https://leetcode.com/problems/unique-binary-search-trees-ii">95. Unique Binary Search Trees II</a></h2><h3>Medium</h3><hr><p>Return every structurally unique binary search tree that stores exactly the values <code>1</code> to <code>n</code>, in any order.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> n = 3
<strong>Output:</strong> [[1,null,2,null,3],[1,null,3,2],[2,1,3],[3,1,null,null,2],[3,2,null,1]]
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> n = 1
<strong>Output:</strong> [[1]]
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= n &lt;= 8</code>.</p>
