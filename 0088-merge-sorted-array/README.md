<h2><a href="https://leetcode.com/problems/merge-sorted-array">88. Merge Sorted Array</a></h2><h3>Easy</h3><hr><p><code>nums1</code> has length <code>m + n</code>: its first <code>m</code> values are sorted and the rest are placeholders. Merge the sorted array <code>nums2</code> (length <code>n</code>) into <code>nums1</code> in place so that the result is sorted.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
<strong>Output:</strong> [1,2,2,3,5,6]
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> nums1 = [0], m = 0, nums2 = [1], n = 1
<strong>Output:</strong> [1]
</pre>
<p><strong>Constraints:</strong> <code>0 &lt;= m, n &lt;= 200</code>.</p>
