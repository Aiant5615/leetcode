<h2><a href="https://leetcode.com/problems/integer-to-roman">12. Integer to Roman</a></h2><h3>Medium</h3><hr><p>Convert an integer to a Roman numeral. The symbols are <code>I</code> 1, <code>V</code> 5, <code>X</code> 10, <code>L</code> 50, <code>C</code> 100, <code>D</code> 500, <code>M</code> 1000. Numerals are written largest to smallest, except for the six subtractive forms <code>IV</code> 4, <code>IX</code> 9, <code>XL</code> 40, <code>XC</code> 90, <code>CD</code> 400, <code>CM</code> 900.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> num = 3749
<strong>Output:</strong> "MMMDCCXLIX"
<strong>Explanation:</strong> 3000 = MMM, 700 = DCC, 40 = XL, 9 = IX.
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> num = 58
<strong>Output:</strong> "LVIII"
<strong>Explanation:</strong> 50 = L, 8 = VIII.
</pre>
<p><strong class="example">Example 3:</strong></p>
<pre>
<strong>Input:</strong> num = 1994
<strong>Output:</strong> "MCMXCIV"
<strong>Explanation:</strong> 1000 = M, 900 = CM, 90 = XC, 4 = IV.
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= num &lt;= 3999</code>.</p>
