<h2><a href="https://leetcode.com/problems/swap-nodes-in-pairs">24. Swap Nodes in Pairs</a></h2><h3>Medium</h3><hr><p>연결 리스트에서 인접한 두 노드씩 자리를 바꾸고 head를 반환하세요. 노드 안의 값을 바꾸지 말고 연결을 바꿔야 합니다.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> head = [1,2,3,4]
<strong>출력:</strong> [2,1,4,3]
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> head = []
<strong>출력:</strong> []
</pre>
<p><strong class="example">예시 3:</strong></p>
<pre>
<strong>입력:</strong> head = [1,2,3]
<strong>출력:</strong> [2,1,3]
</pre>
<p><strong>제약 조건:</strong> 노드 수는 0~100입니다.</p>
