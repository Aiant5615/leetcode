<h2><a href="https://leetcode.com/problems/climbing-stairs">70. Climbing Stairs</a></h2><h3>Easy</h3><hr><p>You climb a staircase of <code>n</code> steps, taking 1 or 2 steps at a time. Return the number of distinct ways to reach the top.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> n = 2
<strong>Output:</strong> 2
<strong>Explanation:</strong> 1+1 or 2.
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> n = 3
<strong>Output:</strong> 3
<strong>Explanation:</strong> 1+1+1, 1+2, 2+1.
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= n &lt;= 45</code>.</p>
