<h2><a href="https://leetcode.com/problems/climbing-stairs">70. Climbing Stairs</a></h2><h3>Easy</h3><hr><p>계단 <code>n</code>개를 한 번에 1칸 또는 2칸씩 오릅니다. 꼭대기까지 오르는 서로 다른 방법의 수를 반환하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> n = 2
<strong>출력:</strong> 2
<strong>설명:</strong> 1+1 또는 2.
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> n = 3
<strong>출력:</strong> 3
<strong>설명:</strong> 1+1+1, 1+2, 2+1.
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= n &lt;= 45</code>.</p>
