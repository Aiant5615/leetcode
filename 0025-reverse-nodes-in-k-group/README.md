<h2><a href="https://leetcode.com/problems/reverse-nodes-in-k-group">25. Reverse Nodes in k-Group</a></h2><h3>Hard</h3><hr><p>Reverse the nodes of a linked list <code>k</code> at a time and return the new head. If the number of nodes left at the end is less than <code>k</code>, leave them as they are. Only links may change, not node values.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> head = [1,2,3,4,5], k = 2
<strong>Output:</strong> [2,1,4,3,5]
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> head = [1,2,3,4,5], k = 3
<strong>Output:</strong> [3,2,1,4,5]
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= k &lt;= n &lt;= 5000</code>.</p>
