<h2><a href="https://leetcode.com/problems/4sum">18. 4Sum</a></h2><h3>Medium</h3><hr><p>Given an integer array <code>nums</code> and an integer <code>target</code>, return all distinct quadruplets <code>[nums[a], nums[b], nums[c], nums[d]]</code> with four different indices whose sum equals <code>target</code>, in any order.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> nums = [1,0,-1,0,-2,2], target = 0
<strong>Output:</strong> [[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> nums = [2,2,2,2,2], target = 8
<strong>Output:</strong> [[2,2,2,2]]
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= nums.length &lt;= 200</code>, <code>-10<sup>9</sup> &lt;= nums[i], target &lt;= 10<sup>9</sup></code> (sums can overflow 32 bits).</p>
