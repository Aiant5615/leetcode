<h2><a href="https://leetcode.com/problems/remove-duplicates-from-sorted-list">83. Remove Duplicates from Sorted List</a></h2><h3>Easy</h3><hr><p>정렬된 연결 리스트의 head가 주어질 때, 각 값이 한 번만 나오도록 중복을 지우고 정렬된 리스트를 반환하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> head = [1,1,2]
<strong>출력:</strong> [1,2]
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> head = [1,1,2,3,3]
<strong>출력:</strong> [1,2,3]
</pre>
<p><strong>제약 조건:</strong> 노드 수는 0~300입니다.</p>
