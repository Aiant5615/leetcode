<h2><a href="https://leetcode.com/problems/rotate-list">61. Rotate List</a></h2><h3>Medium</h3><hr><p>Rotate a linked list to the right by <code>k</code> places and return the new head.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> head = [1,2,3,4,5], k = 2
<strong>Output:</strong> [4,5,1,2,3]
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> head = [0,1,2], k = 4
<strong>Output:</strong> [2,0,1]
</pre>
<p><strong>Constraints:</strong> 0 to 500 nodes, <code>0 &lt;= k &lt;= 2 * 10<sup>9</sup></code>.</p>
