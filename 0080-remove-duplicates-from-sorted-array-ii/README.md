<h2><a href="https://leetcode.com/problems/remove-duplicates-from-sorted-array-ii">80. Remove Duplicates from Sorted Array II</a></h2><h3>Medium</h3><hr><p>Given a non-decreasing array <code>nums</code>, remove duplicates in place so that each value appears at most twice, keeping the order. Return the new length <code>k</code>; the first <code>k</code> slots must hold the result.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> nums = [1,1,1,2,2,3]
<strong>Output:</strong> 5, nums = [1,1,2,2,3,_]
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> nums = [0,0,1,1,1,1,2,3,3]
<strong>Output:</strong> 7, nums = [0,0,1,1,2,3,3,_,_]
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= nums.length &lt;= 3 * 10<sup>4</sup></code>.</p>
