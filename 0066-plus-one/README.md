<h2><a href="https://leetcode.com/problems/plus-one">66. Plus One</a></h2><h3>Easy</h3><hr><p>A large integer is given as an array of <code>digits</code>, most significant first, with no leading zeros. Add one and return the resulting digits.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> digits = [1,2,3]
<strong>Output:</strong> [1,2,4]
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> digits = [4,3,2,1]
<strong>Output:</strong> [4,3,2,2]
</pre>
<p><strong class="example">Example 3:</strong></p>
<pre>
<strong>Input:</strong> digits = [9]
<strong>Output:</strong> [1,0]
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= digits.length &lt;= 100</code>.</p>
