<h2><a href="https://leetcode.com/problems/plus-one">66. Plus One</a></h2><h3>Easy</h3><hr><p>큰 정수가 자릿수 배열 <code>digits</code>(가장 높은 자리부터, 앞자리 0 없음)로 주어집니다. 1을 더한 결과의 자릿수 배열을 반환하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> digits = [1,2,3]
<strong>출력:</strong> [1,2,4]
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> digits = [4,3,2,1]
<strong>출력:</strong> [4,3,2,2]
</pre>
<p><strong class="example">예시 3:</strong></p>
<pre>
<strong>입력:</strong> digits = [9]
<strong>출력:</strong> [1,0]
</pre>
<p><strong>제약 조건:</strong> <code>1 &lt;= digits.length &lt;= 100</code>.</p>
