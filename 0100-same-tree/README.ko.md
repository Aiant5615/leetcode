<h2><a href="https://leetcode.com/problems/same-tree">100. Same Tree</a></h2><h3>Easy</h3><hr><p>두 이진 트리 <code>p</code>, <code>q</code>가 같은지 반환하세요. 구조가 같고 모든 노드의 값이 같아야 합니다.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> p = [1,2,3], q = [1,2,3]
<strong>출력:</strong> true
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> p = [1,2], q = [1,null,2]
<strong>출력:</strong> false
</pre>
<p><strong class="example">예시 3:</strong></p>
<pre>
<strong>입력:</strong> p = [1,2,1], q = [1,1,2]
<strong>출력:</strong> false
</pre>
<p><strong>제약 조건:</strong> 각 트리의 노드 수는 0~100입니다.</p>
