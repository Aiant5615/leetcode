<h2><a href="https://leetcode.com/problems/spiral-matrix-ii">59. Spiral Matrix II</a></h2><h3>Medium</h3><hr><p>Generate an <code>n x n</code> matrix filled with the numbers <code>1</code> to <code>n<sup>2</sup></code> in spiral order.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> n = 3
<strong>Output:</strong> [[1,2,3],[8,9,4],[7,6,5]]
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> n = 1
<strong>Output:</strong> [[1]]
</pre>
<p><strong>Constraints:</strong> <code>1 &lt;= n &lt;= 20</code>.</p>
