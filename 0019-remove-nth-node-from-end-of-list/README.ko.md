<h2><a href="https://leetcode.com/problems/remove-nth-node-from-end-of-list">19. Remove Nth Node From End of List</a></h2><h3>Medium</h3><hr><p>연결 리스트의 <code>head</code>가 주어질 때, 끝에서 <code>n</code>번째 노드를 제거하고 head를 반환하세요.</p>
<p><strong class="example">예시 1:</strong></p>
<pre>
<strong>입력:</strong> head = [1,2,3,4,5], n = 2
<strong>출력:</strong> [1,2,3,5]
</pre>
<p><strong class="example">예시 2:</strong></p>
<pre>
<strong>입력:</strong> head = [1], n = 1
<strong>출력:</strong> []
</pre>
<p><strong class="example">예시 3:</strong></p>
<pre>
<strong>입력:</strong> head = [1,2], n = 1
<strong>출력:</strong> [1]
</pre>
<p><strong>제약 조건:</strong> 노드 수 <code>sz</code>는 <code>1 &lt;= sz &lt;= 30</code>, <code>1 &lt;= n &lt;= sz</code>. <strong>추가 질문:</strong> 한 번의 순회로 풀 수 있나요?</p>
